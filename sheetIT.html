1.2 หน่วยความจำ (Memory)

หน่วยความจำหลัก (Primary Memory)

RAM (Random Access Memory) เป็นหน่วยความจำที่ CPU ใช้พักข้อมูลและคำสั่งระหว่างทำงาน อ่านและเขียนได้รวดเร็ว แต่เป็นหน่วยความจำแบบ Volatile คือข้อมูลจะสูญหายเมื่อไม่มีไฟเลี้ยง

ROM (Read-Only Memory) เป็นหน่วยความจำแบบ Non-volatile ข้อมูลไม่สูญหายเมื่อปิดเครื่อง โดยในระบบสมัยใหม่มักใช้เก็บเฟิร์มแวร์ เช่น UEFI

หน่วยความจำสำรอง (Secondary Storage)

ใช้เก็บข้อมูลระยะยาว เช่น HDD, SSD, USB Flash Drive, Memory Card, CD และ DVD ข้อมูลยังคงอยู่แม้ปิดเครื่อง

เปรียบเทียบVolatileNon-volatile
ความหมายต้องมีไฟเลี้ยงเพื่อรักษาข้อมูลข้อมูลยังอยู่แม้ไม่มีไฟเลี้ยง
ตัวอย่างRAMROM, SSD, HDD, Flash Drive
จำให้แม่น: RAM = ชั่วคราว / Volatile ส่วน ROM และอุปกรณ์จัดเก็บข้อมูล = ไม่ลบเลือน / Non-volatile

02

ซอฟต์แวร์และระบบปฏิบัติการ

Software & Operating System

2.1 ซอฟต์แวร์ (Software)

ซอฟต์แวร์ คือชุดคำสั่งหรือโปรแกรมที่สั่งให้ฮาร์ดแวร์ทำงาน แบ่งกว้าง ๆ เป็น 2 ประเภท

ประเภทความหมายตัวอย่าง
System Softwareควบคุมระบบและจัดการทรัพยากรเครื่องWindows, Linux, macOS, Device Driver, Utility
Application Softwareโปรแกรมสำหรับงานที่ผู้ใช้ต้องการWord, Excel, PowerPoint, Chrome, Photoshop
เทคนิคจำ: Windows เป็นซอฟต์แวร์ระบบ ส่วน Word และ Excel เป็นซอฟต์แวร์ประยุกต์

2.2 ระบบปฏิบัติการ (Operating System: OS)

OS เป็นซอฟต์แวร์ระบบหลัก ทำหน้าที่เป็นตัวกลางระหว่างผู้ใช้ โปรแกรม และฮาร์ดแวร์

  • จัดสรรและจัดการหน่วยความจำ
  • จัดการไฟล์และโฟลเดอร์
  • ควบคุมอุปกรณ์ผ่านไดรเวอร์
  • จัดการกระบวนการและโปรแกรมที่กำลังทำงาน
  • จัดการบัญชีผู้ใช้และสิทธิ์การเข้าถึง
  • สนับสนุนการเชื่อมต่อเครือข่ายและความปลอดภัย

2.5 Malware และความปลอดภัยคอมพิวเตอร์

Malware คือซอฟต์แวร์ที่ออกแบบมาเพื่อทำอันตราย ขโมยข้อมูล หรือรบกวนระบบ

ชนิดลักษณะสำคัญ
Virusแทรกตัวกับไฟล์หรือโปรแกรม และแพร่เมื่อมีการเรียกใช้งาน
Wormแพร่กระจายตัวเองผ่านเครือข่ายได้
Trojanปลอมตัวเป็นโปรแกรมที่ดูปกติ เพื่อหลอกให้ติดตั้งหรือเรียกใช้
Ransomwareเข้ารหัสหรือล็อกข้อมูลเพื่อเรียกค่าไถ่
Spywareแอบติดตามหรือเก็บข้อมูลผู้ใช้
แนวทางป้องกัน: อัปเดตระบบและโปรแกรม ใช้โปรแกรมป้องกันมัลแวร์ ดาวน์โหลดจากแหล่งเชื่อถือได้ ระวังไฟล์แนบและลิงก์แปลกปลอม สำรองข้อมูลสม่ำเสมอ และใช้บัญชีแบบสิทธิ์เท่าที่จำเป็น

PANส่วนบุคคล ระยะใกล้มือถือเชื่อมต่อหูฟัง Bluetooth
LANพื้นที่จำกัดเครือข่ายภายในบ้านหรือสำนักงาน
MANระดับเมืองหรือเขตเมืองเชื่อมโยงเครือข่ายหลายพื้นที่ในเมือง
WANพื้นที่กว้าง ระหว่างเมืองหรือประเทศเครือข่ายองค์กรหลายสาขา; อินเทอร์เน็ตเป็นตัวอย่างเครือข่ายขนาดใหญ่
จำลำดับ: PAN → LAN → MAN → WAN โดยทั่วไปเรียงจากขอบเขตเล็กไปใหญ่

PC — PC — PC — PC
Ringเชื่อมต่อเป็นวงแหวน ข้อมูลเดินทางตามลำดับหรือทิศทางที่กำหนด

4.3 อุปกรณ์เครือข่าย

อุปกรณ์หน้าที่คำจำง่าย
Routerส่งต่อแพ็กเก็ตและเลือกเส้นทางระหว่างเครือข่ายหาเส้นทาง
Switchเชื่อมอุปกรณ์ใน LAN และส่งเฟรมตาม MAC Addressเชื่อมเครื่องในวง LAN
Hubกระจายสัญญาณไปยังทุกพอร์ตโดยไม่คัดเลือกปลายทางส่งให้ทุกพอร์ต
Modemทำหน้าที่มอดูเลต/ดีมอดูเลตหรือแปลงสัญญาณตามเทคโนโลยีผู้ให้บริการเชื่อมต่อสายบริการอินเทอร์เน็ต
Access Pointให้อุปกรณ์ไร้สายเชื่อมต่อเข้าสู่เครือข่ายจุดกระจาย Wi-Fi
Firewallกรองและควบคุมการรับส่งข้อมูลตามนโยบายความปลอดภัยด่านตรวจเครือข่าย

4.4 IP Address

IP Address คือหมายเลขที่ใช้ระบุอินเทอร์เฟซของอุปกรณ์ในเครือข่าย IP เพื่อให้ส่งข้อมูลไปยังปลายทางได้

รุ่นขนาดรูปแบบตัวอย่าง
IPv432 บิต192.168.1.1
IPv6128 บิต2001:db8::1

IPv4 เขียนเป็นตัวเลข 4 ชุดคั่นด้วยจุด ส่วน IPv6 เขียนเป็นเลขฐานสิบหกคั่นด้วยเครื่องหมายโคลอน

4.5 โปรโตคอลเครือข่าย (Network Protocol)

โปรโตคอล คือกฎและมาตรฐานที่กำหนดวิธีการสื่อสารและแลกเปลี่ยนข้อมูลระหว่างอุปกรณ์

โปรโตคอลหน้าที่จุดจำ
HTTPรับส่งข้อมูลเว็บเว็บ
HTTPSHTTP ที่ใช้ TLS เพื่อป้องกันการสื่อสารเว็บเข้ารหัสระหว่างทาง
FTPรับส่งไฟล์File Transfer
SMTPส่งอีเมลส่งเมล
POP3รับ/ดาวน์โหลดอีเมลจากเซิร์ฟเวอร์ดึงเมลลงเครื่อง
IMAPเข้าถึงและซิงก์อีเมลกับเซิร์ฟเวอร์จัดการเมลหลายอุปกรณ์
DNSแปลงชื่อโดเมนเป็นข้อมูลระบุตำแหน่ง เช่น IP Addressชื่อเว็บ → IP
DHCPแจกค่าตั้งค่าเครือข่าย เช่น IP อัตโนมัติแจก IP
TCPขนส่งข้อมูลแบบมีการเชื่อมต่อ ตรวจสอบการส่งและเรียงลำดับเชื่อถือได้
UDPขนส่งข้อมูลแบบไม่สร้างการเชื่อมต่อ มีส่วนควบคุมน้อยกว่าลดขั้นตอน/หน่วงต่ำ
ข้อควรจำ: DNS ช่วยแปลงชื่อโดเมน เช่น example.com ให้ค้นหาปลายทางบนเครือข่ายได้ ส่วน DHCP ช่วยแจกการตั้งค่า IP ให้เครื่องโดยอัตโนมัติ

4.6 อินเทอร์เน็ตและการค้นหาข้อมูล

คำศัพท์ความหมายตัวอย่าง
Internetเครือข่ายของเครือข่ายที่เชื่อมต่อทั่วโลกการใช้งานออนไลน์
Websiteกลุ่มหน้าเว็บที่เกี่ยวข้องกันเว็บไซต์หน่วยงาน
Web Browserโปรแกรมเปิดและแสดงผลหน้าเว็บChrome, Edge, Firefox, Safari
Search Engineบริการค้นหาข้อมูลบนเว็บGoogle, Bing, Yahoo
URLที่อยู่ของทรัพยากรบนอินเทอร์เน็ตhttps://example.com
Domain Nameชื่อที่มนุษย์อ่านจำได้ ใช้แทนการอ้างถึงปลายทางexample.com

4.7 ความปลอดภัยไซเบอร์ (Cybersecurity)

ภัยคุกคามความหมาย
Phishingหลอกให้เปิดเผยรหัสผ่าน ข้อมูลส่วนตัว หรือข้อมูลทางการเงินผ่านข้อความ/เว็บไซต์ปลอม
Hackingการเจาะหรือเข้าถึงระบบ; การกระทำโดยไม่ได้รับอนุญาตเป็นความเสี่ยงด้านความมั่นคงปลอดภัย
Malwareซอฟต์แวร์ประสงค์ร้าย
Ransomwareมัลแวร์ที่ล็อกหรือเข้ารหัสข้อมูลเพื่อเรียกค่าไถ่
Spywareซอฟต์แวร์สอดแนมหรือเก็บข้อมูลโดยไม่เหมาะสม
DDoSโจมตีให้บริการล่มหรือช้าลงด้วยปริมาณคำขอจากหลายแหล่ง

หลักการป้องกัน

  • ตั้งรหัสผ่านยาว ไม่ซ้ำกันในแต่ละบริการ และใช้ Password Manager เมื่อเหมาะสม
  • เปิดใช้การยืนยันตัวตนหลายปัจจัย (MFA/2FA)
  • ไม่เปิดเผยรหัสผ่านหรือ OTP และตรวจสอบผู้ส่งก่อนกดลิงก์
  • อัปเดตระบบปฏิบัติการและโปรแกรมอย่างสม่ำเสมอ
  • สำรองข้อมูล และทดสอบการกู้คืนข้อมูลเป็นระยะ
  • ใช้เครือข่ายที่เชื่อถือได้ และหลีกเลี่ยงการทำธุรกรรมสำคัญผ่าน Wi-Fi สาธารณะที่ไม่ปลอดภัย

CIA Triad: หลักพื้นฐาน 3 ด้านของความมั่นคงปลอดภัยสารสนเทศ

Confidentialityการรักษาความลับ — ผู้ไม่มีสิทธิ์ต้องไม่เข้าถึงข้อมูล
Integrityความถูกต้องครบถ้วน — ข้อมูลไม่ถูกแก้ไขโดยมิชอบ
Availabilityความพร้อมใช้งาน — ผู้มีสิทธิ์เข้าถึงระบบได้เมื่อจำเป็น
จำ CIA: C = ลับ, I = ถูกต้อง, A = พร้อมใช้
